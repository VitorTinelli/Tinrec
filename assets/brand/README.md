# Identidade Tinrec

Símbolo aprovado em 02/11/2026: fita em forma de t, dobra de captura e ponto coral.
O SVG é a fonte vetorial. Cópias públicas atendem os builds independentes do site
(`/public`) e desktop (`/desktop-app/public`). Preserve as cópias iguais.

Paleta: índigo #5969e7 / #211878, coral #ff7c87 e branco.
Ícones nativos são gerados com `rsvg-convert` e `npx tauri icon`, a partir do SVG.
